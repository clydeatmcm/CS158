This table introduces some of the most common Python libraries used in data science and machine learning. These libraries help with organizing data, performing calculations, creating charts, building prediction models, and evaluating how well those models work.

2. Matplotlib and Seaborn → Create graphs and charts.

### Basic Data Science Python Libraries
| Library / Tool                | What It Does (Simple Explanation)                                         | Usage                                                                   |
| ----------------------------- | ------------------------------------------------------------------------- | ----------------------------------------------------------------------- |
| **pandas (pd)**               | Organizes data into tables so it is easy to read and analyze.             | Like a spreadsheet with rows and columns.                               |
| **numpy (np)**                | Helps Python do math and number calculations quickly.                     | Adding or averaging many numbers.                                       |
| **matplotlib (plt)**          | Draws basic charts and graphs.                                            | Creating a bar chart or line graph.                                     |
| **seaborn (sns)**             | Makes charts look nicer and easier to understand.                         | Creating colorful graphs.                                               |
| **train_test_split**          | Splits data into two groups: one for learning and one for testing.        | Like studying with one set of questions and taking a quiz with another. |
| **LabelEncoder**              | Changes words into numbers so the computer can understand them.           | Converting "Yes" = 1 and "No" = 0.                                      |
| **accuracy_score**            | Checks how many answers the computer got correct.                         | Measuring a quiz score.                                                 |
| **confusion_matrix**          | Shows which predictions were correct or incorrect.                        | A report card for predictions.                                          |
| **classification_report**     | Gives detailed results about the computer's predictions.                  | A detailed report card.                                                 |
| **mean_absolute_error (MAE)** | Measures how far predictions are from the real answers.                   | Checking how many points off a guess was.                               |
| **mean_squared_error (MSE)**  | Measures prediction mistakes and gives bigger penalties for large errors. | Punishing bigger mistakes more.                                         |
| **r2_score**                  | Shows how well a model understands the data.                              | A score for how good the prediction is.                                 |
| **DecisionTreeClassifier**    | Makes decisions by following rules like a flowchart.                      | "If age > 18, then Adult."                                              |
| **LinearRegression**          | Predicts a number based on patterns in data.                              | Predicting a student's score based on study hours.                      |
